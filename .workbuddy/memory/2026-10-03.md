## 动效改为苹果官网式滚动联动（用户反馈 2）

- 用户要求动画「快速、简洁、照抄苹果官网效果」。
- 去掉 IntersectionObserver 一次性浮现（0.7s 定时过渡）→ 改为**滚动位置实时驱动**（opacity + translateY 内联，元素顶部从视口底部进入、到 88% 视口高度完全显现，约 80px 滚动距离，快速跟手）。
- 新增 **Hero 视差淡出**：随滚动以 25% 速度上移、过 85% 视口后全隐（pointer-events 同步关闭）。
- Hero 入场动画缩短到 0.55s、cubic-bezier(0.16,1,0.3,1)（快起缓停），stagger 0.03~0.23s；`›` 箭头位移过渡改 0.2s 同款缓动。

## present_files 预览回写坑（重要，详见 MEMORY.md）

- 预览会向磁盘源文件注入 ` data-page-node-id="..."` 垃圾属性；且 present 后短时间内做的 Edit 可能被预览延迟回写**整体回滚**（本次 5 个 Edit 被回滚过一次）。
- 安全流程：Write/Edit → grep 验证落盘 → present → `perl -pi -e 's/ data-page-node-id="[^"]*"//g' index.html` 清理 → 再验证。
