仓库只放 .mm，页面自己读、自己画。这样导图能进 git、能跟随深色模式，也不必为每张图导出两套 PNG。

一、为什么是 .mm

.mm 就是 XML：一个 <map>、一个根 <node>，文字在 TEXT 属性里，子节点嵌套。Freeplane[9] 沿用 FreeMind[4] 的格式，文件头改成 version="freeplane 1.12.15"，并多出富文本、备注、图标、标签、属性与颜色。

<map version="1.0.1">
  <node TEXT="根节点">
    <node TEXT="分支一">
      <node TEXT="叶子"/>
    </node>
    <node TEXT="分支二" FOLDED="true">……</node>
  </node>
</map>

三、解析

只认直接的 <node> 子元素（<font>、<edge>、<icon>、<richcontent> 另行读）。每个节点都带 children，叶子也不能省——markmap 算连线时直接调 children.map()。

function build(el) {
  var node = {
    // 富文本优先：Freeplane 存了 richcontent 就不再写 TEXT
    content: richHTML(el) || escapeHTML(el.getAttribute('TEXT') || ''),
    children: []
  };
  for (var i = 0; i < el.children.length; i++) {
    var child = el.children[i];
    if (child.tagName === 'node') node.children.push(build(child));
  }
  if (el.getAttribute('FOLDED') === 'true') node.payload = { fold: 1 };
  return node;
}

文字一律转义：markmap 把内容当 HTML 插入，一个 & 就能写坏结构。富文本本身是 HTML，需经白名单重建（见第六节）。节点只接受行内 HTML，所以段落折成 <br>，列表折成「· 」，表格折成「甲 · 乙」。

四、渲染

画图交给 markmap[1]。d3[3] 与 markmap-view[2] 自托管在 assets/vendor/，只在导图滚进视野时注入；没有导图的页面一个字节都不多下。

var mm = new window.markmap.Markmap(svg, {
  autoFit: true,
  initialExpandLevel: -1,
  zoom: false,
  pan: false,
  color: function () { return line; },
  lineWidth: function () { return 1.1; }
});
mm.setData(tree).then(function () { mm.fit(); });

默认单色，只有节点带 <edge COLOR> 时才用图里的颜色。文字颜色靠 CSS 变量，把 markmap 的几个变量指回页面即可：

.mindmap .markmap {
  --markmap-text-color: var(--ink);
  --markmap-circle-open-bg: var(--paper);
}

连线颜色是 SVG 属性，只能由 color 参数给。渲染前用 getComputedStyle[6] 读 --mm-line 当默认值，再监听 prefers-color-scheme[7] 重画。

五、坑

color 与 lineWidth 必须是函数。传数组或数字的简写只在 deriveOptions() 里生效，构造函数不调用，渲染时会报 n is not a function。

markmap 内联的 <style> 比 paper.css 靠后，同权重下它赢。选择器写成 .mindmap .markmap 才压得住。

Markmap.create() 内部异步，渲染报错会变成未捕获的 promise，外面包 try/catch 接不到。所以自己 new 实例、setData() 后接 .catch()。

表 1  Freeplane 的写法与页面上的呈现
.mm 里的东西页面上的样子
<richcontent TYPE="NODE">粗体、斜体、下划线、字号、颜色
TYPE="NOTE" / "DETAILS"节点后的 i 标记，悬停或点按弹出气泡
<icon BUILTIN="…"/>对应字形排在文字前，认不出的显示小圆点
TAGS="…"圆角小标签，颜色取样式里的 tagcolor
<attribute NAME VALUE/>节点下方一行小号灰字
LINK="…"整块文字变成链接，新标签页打开
COLOR、BACKGROUND_COLOR、<font>文字颜色、底色、相对字号（12 号 = 1em）
<edge COLOR="…"/>这一支连线的颜色

富文本经白名单重建：段落、列表、表格压成行，行内只留 b、i、u、s、code、a、br、img，on* 事件与 javascript:、file: 链接丢掉。深色模式下过暗的字色自动提亮，有底色的节点按底色挑黑字或白字；换主题时重新解析整棵树。

不还原 Freeplane 样式表、箭头链接、云与 LaTeX 公式。要纯文字单色，给容器加 data-plain。

七、使用

存成 .mm 丢进 mindmaps/，文章里写两行：

<div class="mindmap" data-src="/mindmaps/xxx.mm"></div>
<script src="/assets/js/mindmap.js" defer></script>

一个页面可放多张，各自写 data-src。全部文件只有三处：mindmap.js（约 600 行）、assets/vendor/ 的 d3 与 markmap-view、mindmaps/ 下的源文件。托管在 GitHub Pages[8]，免费。
